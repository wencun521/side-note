WHY IT FEELS DIFFERENT

没有后台，没有账号，
只有一张随手可用的纸。

所有交互都围绕一件事：别打断你正在做的事。它不弹通知、不占任务栏，也不要求你切换窗口。

01

从球里长出来

便签的展开原点就是悬浮球球心，圆角、描边、毛玻璃一起长大，中途不会闪白底。

02

四条边都能停

按住笔球拖到任意一边，松手吸附到最近的边缘，位置下次打开还在。

03

移开就收起

写完把鼠标移开一秒，便签缩回笔球。需要它多留一会儿时，点一下固定。

04

只留在本机

正文保存在本地浏览器存储里，不登录、不联网、不做同步，关掉应用也还在。

05

需要时钉住

固定后不再自动收起，适合对着资料抄写、贴一段临时清单，或者让它陪你看完一集。

06

键盘也顺手

打开即聚焦正文，输入自动保存，Esc 随时收起。没有多余的确认和弹窗。

HOW IT WORKS

玻璃不是滤镜，
是提前拍下的一张桌面。

Windows 的系统毛玻璃只能铺满整个矩形窗口，跟不上圆角和形变，所以这里换了一种做法：把桌面截图裁成便签大小，模糊后夹在两层之间。

  • 两块透明窗口。96×96 的停靠层负责笔球和拖拽，384×560 的舞台负责便签。
  • 形变只改 transform。球和便签共用一个原点，底图反向缩放，所以玻璃看起来是静止的。
  • 点击不等待 IO。截图在空闲时缓存，点击到窗口显示实测 9–19ms。
  • 先显示，再隐藏。便签窗口接管笔球之后，停靠层才退场，没有空档。

DESIGN NOTES

安静，是设计的一部分。

一套很小的视觉系统：一个琥珀色、一层霜、几条 1px 的高光边。所有强调都只发生在需要被看见的那一刻。

颜色

#C4832C琥珀 #20242C墨 #F4F6FA霜 #F4EFE6纸

颜色不承担装饰，只承担状态：琥珀是光标、固定和正在发生的事。

形状

24 999 9

贴边一侧是直角，另一侧 24px；球和玻璃条永远保持圆形与胶囊，不参与形变。

字与节奏

把想到的，先写下来。 15px · 1.72 · 0.01em · Segoe UI Variable

正文 15px，标题 11px 且拉宽字距。动效只用 transform 和 opacity，展开 500ms，收起 330ms。

RUN IT LOCALLY

在 Windows 上跑起来。

目前以源码方式使用，Windows 安装包、托盘和开机自启还在规划中。官网上的便签是交互复刻，真实应用由 Electron 双窗口驱动。

Windows 11 Node.js 24+ 无需账号 
# 在项目根目录
npm install
npm run dev

开发模式会同时启动 Vite 与 Electron；npm run build 产出静态页面。
